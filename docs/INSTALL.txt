Sniff 0.3.4 preview. Requires macOS 14 or later.

1. Open the DMG.
2. Drag Sniff to Applications.
3. Eject the disk image and open Sniff from Applications.

Quit Sniff before replacing an older copy. Settings and scan history stay in place. Copying the app does not run a cleanup.

The optional CLI has separate setup instructions:
https://github.com/JohnRenatoDev/sniff-cleaner/blob/main/docs/cli.md

This preview has an ad hoc signature and has not been notarized by Apple. macOS may block a downloaded preview. Inspect the repository and verify SHA256SUMS before deciding whether to allow it in System Settings > Privacy & Security. Do not disable Gatekeeper globally. Developer ID signing and Apple notarization are still required for a trusted public release.
